## Common themes across the calls

- **AI demand exceeds supply.** Every hyperscaler said capacity — power, GPUs, data-center
  shells — remains the binding constraint, with tightness expected to persist into 2027–2028.
- **Capex is still climbing.** Combined CY2026 capital-spending guidance across the four now
  runs well north of half a trillion dollars, explicitly tied to AI infrastructure.
- **Backlog is exploding.** Commercial RPO / backlog set records at Microsoft ($678B),
  Oracle ($638B), and Google Cloud ($514B), driven by large multi-year AI commitments.
- **Custom silicon matters.** Amazon (Graviton/Trainium), Google (TPU), and Microsoft
  (Maia) all leaned on in-house chips for efficiency and margin.
- **Cloud margins expanding.** AWS (39%) and Google Cloud (35.6%) both posted sharp
  operating-margin gains on efficiency and scale.

## Scope

"Hyperscaler" here = the three public-cloud majors (Microsoft, Amazon, Alphabet) plus
Oracle/OCI, which is now routinely grouped with them for AI infrastructure. Meta is
included as an AI-capex peer — it runs hyperscale infrastructure but sells no public cloud,
so it appears in the AI-capex table rather than the cloud scorecard.
